# Daily standup

- Tên file: `YYYY-Www-standup.md`; một file cho cả tuần, mỗi ngày một heading.
- Tạo từ [standup template](../../pm/templates/daily-standup-week.md).
- Chỉ ghi outcome hôm qua, kế hoạch hôm nay, blocker và link Jira issue.
- Không tạo checklist task song song Jira. Blocker hoặc thay đổi owner/deadline
  phải được cập nhật lại Jira ngay sau standup.
