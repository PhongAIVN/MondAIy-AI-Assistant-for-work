# Weekly reports

- Tên file: `YYYY-Www-weekly-report.md`, ví dụ
  `2026-W31-weekly-report.md`.
- Tạo từ [weekly template](../../pm/templates/weekly-status-report.md).
- PM phát hành cuối tuần; report link Jira sprint/filter, PR, demo và evidence.
- Không copy toàn bộ danh sách issue hoặc tự duy trì phần trăm tiến độ ngoài
  Jira.
