# Meeting notes and transcripts

- Tên note: `YYYY-MM-DD-chu-de-meeting-notes.md`.
- Tạo từ [meeting template](../../pm/templates/meeting-note.md).
- Git lưu agenda, decision, rationale, action và link evidence.
- Raw transcript/recording mặc định nằm ngoài Git ở kho hạn chế quyền; note chỉ
  lưu link, owner, quyền truy cập và ngày xóa dự kiến.
- Chỉ commit transcript khi đã có consent, được redacted và thật sự cần để tái
  lập một bằng chứng. Không commit secret hoặc PII.
