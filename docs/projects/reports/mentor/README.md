# Mentor duty reports

- Tên file: `YYYY-MM-DD-mentor-duty-report.md`.
- Tạo từ [mentor template](../../pm/templates/mentor-duty-report.md).
- Ghi câu hỏi đã xin ý kiến, khuyến nghị của mentor, quyết định của team và
  action đã chuyển sang Jira.
- Nếu mentor chưa phê duyệt, ghi rõ `Proposed`; không trình bày như quyết định
  cuối.
