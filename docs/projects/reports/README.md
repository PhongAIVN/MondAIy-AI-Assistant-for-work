# Reports

Đây là index cho báo cáo vận hành đã phát hành. Report là bản tổng hợp theo kỳ,
không phải nơi quản lý task hoặc quyết định sản phẩm.

| Loại | Vị trí | Quy ước |
| --- | --- | --- |
| Weekly report | [`weekly/`](weekly/README.md) | Một file mỗi tuần |
| Mentor duty report | [`mentor/`](mentor/README.md) | Một file mỗi buổi/kỳ trực |
| Daily standup | [`standup/`](standup/README.md) | Một file cuộn theo tuần |
| Meeting notes | [`meetings/`](meetings/README.md) | Một file mỗi cuộc họp |
| Demo feedback | [`demos/`](demos/README.md) | Một file mỗi demo/checkpoint |
| Impact report | [`impact/`](impact/README.md) | Báo cáo tổng kết theo release/Gate |

Task, bug, sprint, owner và deadline vẫn nằm ở Jira. Report chỉ link Jira
filter/issue và nêu insight, blocker, decision hoặc evidence cần lưu lại.
